# embr3-ocsm-web

This is the web app for **EMBR3 OCSM**: the public client survey and the staff admin panel. It is built with React 18, Vite 7 and Ant Design 5, and is served under `/ocsm/`.

For what the project is, how to set it up and how to deploy it, see the [project README](../README.md).

```bash
npm install
npm run dev      # http://localhost:5174/ocsm/ (proxies /ocsm/api to the server)
npm run build    # production build in dist/
```
